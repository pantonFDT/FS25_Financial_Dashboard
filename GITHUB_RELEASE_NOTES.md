# Financial Dashboard v2.0.0.0

## What's new since v1.0.0.0

- Financial history now persists per savegame across saves and restarts.
- Balance tracking begins automatically when a farm loads.
- New 7-day view alongside 30-day and 60-day windows.
- New Balance, Inflows, and Outflows graph modes.
- Added daily net-change comparisons and improved tracking of observed balance movements.
- Redesigned the financial graph with refined gridlines, cyan/pink trends, and subtle inflow/outflow indicators.
- Fixed history restoration when the player farm ID is unavailable.
- Improved graph label sizing and spacing.

**Compatibility:** Farming Simulator 25, PC single-player only.  
**Installation:** Download the attached `FS25_FinancialDashboard.zip` and place it in the game's mods folder without extracting it.

**Note:** Transactions are estimated from observed balance changes; the dashboard does not provide categorized accounting records.
